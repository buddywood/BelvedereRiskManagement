# AKILI Risk Intelligence — Logo delivery kit

Delivery copies of the `media/` brand kit for decks, scripts, and docs.
Runtime web assets live in `public/brand/` and site-root favicons.

## Variants

| File | Use |
|------|-----|
| `akili-horizontal-primary.svg` | Light backgrounds — nav, headers |
| `akili-horizontal-white.svg` | Dark UI |
| `akili-horizontal-secondary.svg` | Navy brand backgrounds |
| `akili-horizontal-black.svg` | One-colour / print |
| `akili-vertical-primary.svg` | Stacked — decks, footers |
| `akili-vertical-white.svg` | Stacked on dark |
| `akili-icon-color.svg` | Favicon / compact mark |
| `akili-horizontal-compact.*` | Compat alias → Primary horizontal |
| `akili-stacked.*` | Compat alias → Primary vertical |

## Palette

- **Brand primary:** `#0564b6`
- **Trust accent:** `#f89c11`
- **Ink:** `#0b0d1c` / `#061734`
- **Typeface (in SVG):** Montserrat
